# Desktop 生命周期

## 窗口

- 主窗口使用 Windows 原生边框和最小化、最大化、关闭按钮。
- 悬浮窗口是独立的置顶 Tauri 窗口，加载 Web 的悬浮面板路由。
- 两个窗口只共享控制接口和 Web 状态，不分别启动后台服务。

## 启动顺序

```text
建立单实例保护
    → Windows 按应用清单授予桌面管理员令牌
    → 创建 Windows 作业对象并以继承令牌启动 proxyService
    → 创建系统托盘
    → 创建主窗口与悬浮窗口
    → 显示主窗口
```

WinDivert 的 SOCKET、FLOW 与 NETWORK 层要求管理员令牌。权限声明固定嵌入桌面可执行文件，
后端不执行第二次提权，也不会在用户保存进程选择时才尝试改变令牌；这保证桌面、后台服务和
受作业对象管理的生命周期使用同一个明确的权限边界。

如果后台程序启动失败，守护线程继续按固定间隔重试；桌面外壳保持可退出，Web 通过真实的
控制连接失败状态呈现异常，不能构造“已停止”快照掩盖失败。

## 关闭顺序

关闭主窗口只执行隐藏。托盘“退出”执行：

1. 标记桌面生命周期正在退出。
2. 立即终止直属 `proxyService`，不等待 Socket、插件或远端连接自行结束。
3. 终止 Windows 作业对象中的全部插件和辅助子进程。
4. 释放托盘、窗口和作业句柄后退出。

代理进程在启动成功返回前必须加入作业对象；绑定失败会同步回收该进程并报告启动失败，禁止降级为无监管运行。桌面崩溃或被强制结束时，Windows 内核通过 `KILL_ON_JOB_CLOSE` 自动终止完整代理进程树。
