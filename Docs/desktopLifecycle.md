# Desktop 生命周期

## 窗口

- 主窗口使用 Windows 原生边框和最小化、最大化、关闭按钮。
- 悬浮窗口是独立的置顶 Tauri 窗口，加载 Web 的悬浮面板路由。
- 两个窗口只共享控制接口和 Web 状态，不分别启动后台服务。

## 启动顺序

```text
建立单实例保护
    → 启动或确认 proxyService
    → 创建系统托盘
    → 创建主窗口与悬浮窗口
    → 显示主窗口
```

如果后台程序启动失败，守护线程继续按固定间隔重试；桌面外壳保持可退出，Web 通过真实的
控制连接失败状态呈现异常，不能构造“已停止”快照掩盖失败。

## 关闭顺序

关闭主窗口只执行隐藏。托盘“退出”执行：

1. 标记桌面生命周期正在退出。
2. 请求后台停止 SOCKS5 监听和活动会话。
3. 最多等待三十五秒，覆盖 SOCKS5 数据面三十秒关闭上限、HTTP 控制面一秒排空和进程退出余量。
4. 超时后终止仍属于当前桌面实例的子进程。
5. 释放托盘和窗口后退出。

## 单实例

第二个桌面实例不创建新后台进程，而是激活既有主窗口。窗口尺寸、位置和分隔条比例由
Web 与 Tauri 各自在对应职责层保存。
