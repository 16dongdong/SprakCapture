# 35 UI 壳层、层级与对话框体系

本文定义 **界面层级** 与 **Charles 式对话框配置** 的统一落点。
各功能文档的「UI 操作指南」必须遵守：工具/代理类配置进 **对话框**，主窗口只做观察与分析，禁止把规则编辑堆成与工作台平级的大页面。

**组件级视觉 / 交互 / 按钮语义** 见 [36-componentSpec.md](36-componentSpec.md)。

## 0. 设计原则（对齐 Charles）

| 原则 | 说明 |
|---|---|
| **工作台优先** | 主窗口默认且核心是「连接会话」结构报文 + 检查器；概览为次级只读仪表 |
| **配置进对话框** | Map/Rewrite/断点/节流/SSL/录制设置/代理端口等 **均以模态对话框** 编辑，与 Charles Tools / Proxy 菜单一致 |
| **菜单与右键双入口** | 菜单打开完整配置对话框；右键可「一键添加规则」并预填 Location，仍落到同一对话框体系 |
| **层级不可压扁** | 同一屏幕不得出现「工作台 + 全页工具编辑 + 全页设置」三套平级主内容；配置层叠在遮罩对话框中 |
| **一对话框一职责** | 禁止「超级设置」一页塞满所有工具；每个工具独立对话框，可再嵌套「添加规则」子对话框 |
| **能折则折、忌平铺** | 次要说明、高级选项、长规则细节、帮助文案等 **优先用折叠/展开**（Disclosure / Accordion / 树节点），默认只露出当前任务所需控件；禁止把所有字段一次性平铺占满对话框或检查器 |

## 1. 界面层级（强制）

从外到内、从底层到浮层：

```text
L0  操作系统 / 托盘
L1  应用窗口壳（标题栏、菜单栏、顶栏、底栏）
L2  主工作区页面（概览 | 连接会话）—— 唯一“常驻”业务平面
L3  模态对话框（工具设置、代理设置、导入导出…）—— 配置平面
L4  子对话框 / 确认框 / 断点编辑器 / 文件选择 —— 瞬时决策平面
```

### 1.1 各层职责

| 层级 | 允许出现 | 禁止出现 |
|---|---|---|
| **L1 壳** | 菜单、顶栏开关、底栏状态、导航到 L2 | 规则 CRUD 表单本体 |
| **L2 主工作区** | 结构报文、检查器、概览卡片、筛选 | 完整工具配置表（应用级规则编辑器） |
| **L3 对话框** | 工具总开关、规则列表、设置分组表单、应用/取消 | 替代整个连接会话工作台 |
| **L4 子层** | 单条规则编辑、断点改包、确认、文件/目录选择 | 再开平行 L3 导致无限叠层（最多 L3+L4） |

### 1.2 视觉层级（实现约束）

| 元素 | 视觉权重 | 规范 |
|---|---|---|
| 菜单栏 + 顶栏 | 中 | 高度紧凑；开关状态用填充色，不用大按钮墙 |
| 连接会话三栏 | **最高** | 占满 L2；分隔条可调；信息密度 Charles 式 |
| 检查器页签 | 高 | 次于表格选中行，正文区可读 |
| 底栏 | 低 | 单行状态，错误可点 |
| L3 对话框 | 浮在遮罩上 | 居中；默认宽约 560–720px，规则表类可 800–960px；高度最大 80vh，表体内部滚动 |
| L4 | 高于 L3 | 确认框窄；规则编辑可与父对话框同宽或略窄 |
| 遮罩 | 压暗 L2 | 点击遮罩默认不关闭（防误触丢编辑）；仅取消/Esc/应用关闭 |
| Toast | 最高瞬时 | 不挡对话框主按钮 |

### 1.3 焦点与快捷键

- 打开 L3：焦点进入对话框首个可编辑控件或规则表。
- `Esc`：L4 先关；再 Esc 关 L3（有未应用更改则确认）。
- `Enter`：在单行确认框等于确定；规则表对话框不绑定 Enter 提交，避免误触。
- 主工作区快捷键在 L3 打开时禁用或降级，避免「后台改选中行」。

## 2. 窗口与路由（精简主平面）

| 窗口 | 路由 | 层级 | 职责 |
|---|---|---|---|
| 主窗口 | `/overview`、`/connections` | L1+L2 | 观察与分析；**不设** `/tools` 全页 |
| 悬浮窗 | `/floating` | L1 精简 | 状态 + 录制/启停/节流/断点开关；点「设置」回主窗或弹 L3 |
| 对话框 | **无独立路由**（推荐） | L3/L4 | 状态由 React 全局 dialog store 管理；URL 可选 `?dialog=mapLocal` 仅便于深链 |

**取消** 将「工具」「设置」作为与连接会话平级的常驻主 Tab 承载重表单。
设置类能力改为：**菜单「代理 / 工具 / 文件」→ L3 对话框**；可选保留极简 **「偏好」** 对话框（界面列、聚焦主机列表等本机 UI）。

Desktop：关主窗口 → 托盘；见 §7。

## 3. 主窗口骨架（L1 + L2）

```text
┌─ L1 菜单栏 ─────────────────────────────────────────────────────────────┐
│ 文件(F)  代理(P)  工具(T)  视图(V)  帮助(H)                                 │
├─ L1 顶栏 ───────────────────────────────────────────────────────────────┤
│                          刷新 清空 导出… 悬浮窗  [启动/停止服务]            │
├─ L2 主工作区 ───────────────────────────────────────────────────────────┤
│  （仅概览 或 连接会话三栏工作台）                                          │
├─ L1 底栏 ───────────────────────────────────────────────────────────────┤
│ 控制连接 · 数据面 · 录制 · 已启用工具摘要 · 断点挂起 · 错误                 │
└─────────────────────────────────────────────────────────────────────────┘

打开工具时叠在上方：

┌─ 遮罩 ──────────────────────────────────────────────────────────────────┐
│   ┌─ L3 对话框：Map Local ──────────────────────────── [−][□][×] ─┐   │
│   │ ☑ 启用 Map Local                                              │   │
│   │ [规则表……………………]  [添加…][编辑…][删除][上移][下移]              │   │
│   │                                    [取消]  [应用]  [确定]       │   │
│   └───────────────────────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────────────────────────┘
```

### 3.1 主导航（仅两个主平面）

| 标签 | 路径 | 用途 |
|---|---|---|
| 概览 | `/overview` | 指标、监听摘要、入口健康（只读为主） |
| 连接会话 | `/connections` | **默认页**：结构报文 + 检查器 |

顶栏不出现「工具」「设置」平级大页；配置全部走菜单/对话框。

### 3.2 顶栏快捷（开关，不是配置器）

| 控件 | 作用 | 详细配置入口 |
|---|---|---|
| 录制 | 开/暂停录制 | 代理 → 录制设置… |
| 节流 | 启用当前节流档 | 代理 / 工具 → 带宽限制设置…（双击顶栏或菜单） |
| 断点 | 断点总开关；角标=挂起数 | 工具 → 断点设置…；挂起时自动 L3/L4 编辑器 |
| 刷新 / 清空 | 瞬时动作 | 清空 → L4 确认 |
| 导出… | 打开导出对话框 | L3 |
| 悬浮窗 | 打开悬浮窗 | — |
| 启停服务 | 数据面状态机 | — |

**约定**：顶栏图标 **右键** 或 **长按/▾ 小三角** 可直接打开对应设置对话框（Charles 用户习惯：开关与设置分离）。

### 3.3 底栏（L1 信息层）

从左到右单行，不得折成第二工具条：

1. 控制连接状态
2. 数据面监听摘要
3. 录制状态与体积
4. 已启用工具短名列表（可点 → 打开该工具 L3）
5. 断点挂起数（可点 → 断点队列）
6. 最近错误（可点 → 详情对话框）

## 4. 菜单栏结构（配置入口权威）

对齐 Charles：配置能力挂在菜单，菜单项带 `…` 表示打开对话框。

### 4.1 文件

| 菜单项 | 打开 |
|---|---|
| 导入会话… | L3 导入 |
| 导出会话… | L3 导出 |
| 清空会话 | L4 确认 |
| 退出 | 退出应用 |

### 4.2 代理（Proxy）

| 菜单项 | 打开的 L3 对话框 |
|---|---|
| 开始/暂停录制 | 无对话框（等同顶栏） |
| 录制设置… | 限额、忽略列表、隧道元数据 |
| 代理设置… | HTTP/SOCKS 监听、超时、认证等（可内含页签） |
| SSL 代理设置… | MITM 开关、主机表、导出/安装证书 |
| 带宽限制设置… | 预设与自定义速率 |
| 访问控制… | ACL |
| 外部代理设置… | 上游代理 |
| 端口转发… | 端口转发规则 |
| 反向代理… | 反向代理规则 |

> 对话框标题与菜单文案一致，例如标题栏写「SSL 代理设置」。

### 4.3 工具（Tools）

| 菜单项 | L3 对话框 |
|---|---|
| 屏蔽列表… | Block / Allow 模式与列表 |
| 无缓存… | 启用 + Location |
| 阻止 Cookie… | 启用 + Location |
| Map Remote… | 规则表 |
| Map Local… | 规则表 |
| Rewrite… | 重写集与规则 |
| 断点… | 断点规则 + 链到挂起队列 |
| DNS 欺骗… | 域名→IP 表 |
| 镜像… | 目录与 Location |
| 自动保存… | 间隔与目录 |
| 客户端进程… | 启用与范围 |
| （分隔线） | |
| 重复 | 无对话框，对当前选中立即执行 |
| 编辑并重复… | L3/L4 请求编辑器 |
| 高级重复… | L3 负载参数 |
| 验证响应… | L3（P3） |

菜单项前可显示 **勾选标记** 表示工具总开关已开（与对话框内勾选同步）。

### 4.4 视图

| 菜单项 | 行为 |
|---|---|
| 结构 | 左栏唯一事务导航 |
| 聚焦主机… | L3 管理聚焦列表 |
| 显示聚焦主机 only | 勾选过滤 |
| 悬浮窗 | 打开悬浮窗 |
| 工具栏 / 状态栏 | 显示隐藏（可选） |

### 4.5 帮助

| 菜单项 | 行为 |
|---|---|
| 安装根证书… | 向导 L3 |
| 移动设备抓包… | 图文 + 二维码 L3 |
| 文档 | 外链或内嵌 |
| 关于 | L3 |

## 5. 标准对话框模式（L3）

### 5.1 工具类对话框布局（规则表型）

适用于：Map Local/Remote、Rewrite、断点、屏蔽、DNS、镜像等。

```text
┌─ {工具名} ──────────────────────────────────────────────┐
│ ☑ 启用 {工具名}                                          │
│ 说明文字一行（可折叠）                                     │
│ ┌─ 规则 ─────────────────────────────────────────────┐ │
│ │ ☑  匹配位置              目标/动作           ⋮     │ │
│ │ ☑  example.com /api/*    D:\mock\...               │ │
│ └────────────────────────────────────────────────────┘ │
│ [添加…] [编辑…] [删除] [上移] [下移]                      │
│                                                          │
│                    [取消]    [应用]    [确定]             │
└──────────────────────────────────────────────────────────┘
```

| 按钮 | 语义 |
|---|---|
| **应用** | 写入后端，**对话框不关**（便于连改多条） |
| **确定** | 应用并关闭 |
| **取消** | 丢弃未应用草稿并关闭 |

- 表内 **行勾选** = 单条规则启用，即时或随应用（与「工具总开关」独立）。
- **添加… / 编辑…** → 打开 **L4 规则编辑子对话框**（Location 控件 + 工具专用字段）。
- 从结构树右键「Map Local…」：打开 L3，并 **自动打开 L4** 且 Location 预填。

### 5.2 设置类对话框布局（表单/页签型）

适用于：代理设置、SSL、录制设置、上游、ACL。

```text
┌─ 代理设置 ─────────────────────────────────────────────┐
│ [HTTP 代理] [SOCKS5] [高级]     ← 对话框内页签，不是主导航 │
│                                                          │
│  监听主机 [127.0.0.1    ]  端口 [8888]                    │
│  ☑ 启用 HTTP 代理                                        │
│  …                                                       │
│                                                          │
│                    [取消]    [应用]    [确定]             │
└──────────────────────────────────────────────────────────┘
```

运行中锁定的字段禁用，旁注「请先停止服务」。

### 5.3 向导类对话框

适用于：证书安装、移动端接入。步骤条 + 上一步/下一步/完成；不与规则表混用。

### 5.4 断点命中（特殊 L3/L4）

- 非「设置」，而是 **会话中断编辑器**。
- 可多条队列：左侧挂起列表，右侧草稿编辑（头/正文）。
- 按钮：**继续** / **中止** / **全部继续**；不叫确定/取消。
- 始终置顶于普通设置对话框之上。

### 5.5 单一开关型小对话框

适用于：无缓存、阻止 Cookie、客户端进程。

- 启用勾选 + Location 范围（全部 / 选定位置列表）。
- 选定位置时用迷你规则表 + 添加…（L4）。

## 6. 连接会话工作台（L2 核心）

```text
┌─────────────────────────────────┬────────────────────────┐
│ 结构：端点分组 + 筛选 + 事务报文    │ 检查器页签              │
│                                 │ 概览|请求|响应|…        │
└─────────────────────────────────┴────────────────────────┘
```

### 6.1 结构主机右键 → 对话框

| 菜单项 | 行为 |
|---|---|
| 聚焦 / 取消聚焦 | 即时，无对话框 |
| 忽略主机（不录制） | 写入忽略；可再开「录制设置」查看 |
| 启用/取消 SSL 代理 | 即时改主机表 |
| 屏蔽主机 | 打开屏蔽列表 L3 并预填规则 |
| 阻止 Cookie / 无缓存 | 打开对应 L3 并预填 Location |
| Map Local… / Map Remote… | L3 + 可选 L4 预填 |
| Rewrite… / 断点… / DNS 欺骗… | 同上 |
| 复制主机名/路径 | 剪贴板 |

菜单文案带 `…` 的 **必须** 打开对话框；不带则即时生效。

### 6.2 结构报文右键

| 菜单项 | 行为 |
|---|---|
| 重复 | 即时 |
| 编辑并重复… | L3/L4 编辑器 |
| 高级重复… | L3 |
| 保存请求/响应… | 系统文件对话框（L4） |
| 导出选中… | L3 |
| Map / 断点 / 屏蔽… | 同结构主机入口，预填 URL Location |

### 6.3 检查器

仍为 L2 内嵌分析区；**不**承载工具规则配置。
「工具」页签只读展示 `appliedTools`；点工具名可 **打开对应 L3**（跳转配置，非在检查器内嵌编辑）。

- [ ] 主窗口仅「概览 | 连接会话」两个业务主 Tab

- [ ] 底栏点工具名能打开对应 L3

## 9. 与各功能文档的同步约定

各功能「UI 操作指南」应写作：

- **界面位置**：菜单路径（如 `工具 → Map Local…`）+ 右键路径 + 顶栏开关（若有）
- **如何打开**：打开的是 **「Map Local」对话框**，不是「打开工具对话框」
- **操作步骤**：在对话框内勾选启用 → 添加… → L4 填规则 → 应用/确定
- **预期行为**：对话框关闭后工作台可见痕迹；规则保留

权威层级与模式以本文为准；功能文档不得再描述「工具页左侧清单 + 右侧全页编辑」为主路径。  
对话框尺寸、按钮顺序、Esc/脏状态、RulesTable 等实现细节以 [36](36-componentSpec.md) 为准。
