# 42 国际化（i18n）与语言支持

## 1. 定位

Sprak Capture **面向国际用户**：界面、控制面错误信息、Desktop 托盘/菜单、MCP 返回文案均支持 **国际主流语言**。
语言包与功能 **同步交付**——每完成一块用户可见能力，必须补齐 **全部一等语言** 的文案键，禁止「只写中文硬编码、其它语言以后再说」。

| 通道 | 是否 i18n |
|---|---|
| Web / Desktop UI | 是 |
| 控制 API 错误 `message` | 是（按请求语言） |
| MCP tool 错误/摘要 | 是（参数 `locale` 或请求头） |
| `Skill` | 默认 **中文 + 英文** 双语文档（AI 手册，不要求 10 语全文） |
| 日志（开发者） | 可用英文键 + 可选本地化；默认英文键便于检索 |

## 2. 一等语言清单（必须同步维护）

以下语言为 **一等（Tier-1）**：任一用户可见字符串合并时，**所有 Tier-1 语言包必须同时有键**，缺一不可合并为「功能完成」。

| 代码 | 语言 | 备注 |
|---|---|---|
| `en` | English | 键语义基准之一；国际默认回退 |
| `zh-Hans` | 简体中文 | 产品历史默认展示语言 |
| `zh-Hant` | 繁體中文 | 台港等 |
| `ja` | 日本語 | |
| `ko` | 한국어 | |
| `es` | Español | |
| `fr` | Français | |
| `de` | Deutsch | |
| `pt-BR` | Português (Brasil) | |
| `ru` | Русский | |

**Tier-2（可后续加，加后升一等规则相同）：** `it`、`vi`、`tr`、`pl`、`nl`、`ar`（RTL 需单独验收）等。

- 新增一等语言 = 改本文清单 + 补全历史键 + 计划 catalog。  
- **禁止** 只合并 `en`/`zh-Hans` 两份、其它语言空着标完成。

## 3. 默认语言与回退

```text
用户显式选择
  → OS / 浏览器语言（BCP 47 协商）
    → en
      → zh-Hans（最后兜底文案，避免空白）
```

- 设置项：`ui.locale` = `auto` | 具体代码；持久化到用户数据目录。  
- 控制 API：优先 `Accept-Language`；可覆盖查询参数 `?locale=ja`。  
- MCP：tool 参数可选 `locale`；缺省 `en`（机器调用友好）或继承环境 `CAPTURE_LOCALE`。

## 4. 架构

```text
┌─ Frontend (Web) ─────────────────────────────┐
│  i18n 运行时（如 i18next）                     │
│  locales/{en,zh-Hans,...}/app.json           │
│  组件只使用 t('key')，禁止硬编码用户句          │
└──────────────────────────────────────────────┘

┌─ proxyService ───────────────────────────────┐
│  错误：ErrorCode + 参数                        │
│  messageCatalog.render(code, locale, params) │
│  locales/{locale}/errors.json                │
└──────────────────────────────────────────────┘

┌─ capture-mcp ─────────────────────────────────┐
│  透传控制面 locale；自身元数据文案用 catalog   │
└──────────────────────────────────────────────┘

┌─ Desktop ────────────────────────────────────┐
│  托盘/系统对话框：复用同一套键或同步 en/zh 包  │
└──────────────────────────────────────────────┘
```

**单一键空间（推荐）：**

| 前缀 | 用途 |
|---|---|
| `app.*` | 壳、导航、通用按钮 |
| `page.overview.*` / `page.connections.*` | 页面 |
| `dialog.*` | 对话框标题与字段 |
| `tool.mapLocal.*` 等 | 各工具 |
| `error.*` | 前后端共用错误码文案 |
| `mcp.*` | MCP 描述性字符串（若需） |

键名 **稳定英文路径**；翻译只改 JSON 值。

## 5. 文案规则

1. **组件内禁止** 直接写死中文/英文句子（测试 snapshot 可用键名）。  
2. 插值：`{name}` / ICU MessageFormat（复数、性别按语言需要逐步启用）。  
3. 专有名可不译：`Map Local`、`SOCKS5`、`HAR`、`Sprak Capture`。
4. 日期/数字：用 `Intl` 按 locale 格式化。  
5. 长度：德/俄等预留 UI 弹性，避免写死宽度截断关键操作。  
6. **伪本地化（可选 CI）**：`en` → 加前后缀检测漏网硬编码。

## 6. 与功能同步（DoD）

任一用户可见功能 **「已完成」** 必须：

1. 功能代码可用  
2. MCP + Skill 同步（见 40/41）  
3. **i18n**：新增/修改的键已写入 **全部 Tier-1** 语言文件  
4. 切换语言冒烟：该功能路径下无英文键裸露（或 zh 硬编码残留）  

机器可检：

```text
compareKeys(en, zh-Hans, ja, ...) == equal key set
no raw CJK/Latin sentences in TSX except tests
```

## 7. 控制面错误

```json
{
  "code": "invalidConfiguration",
  "message": "配置无效。",
  "messageKey": "error.invalidConfiguration",
  "params": {}
}
```

- 客户端优先展示 `message`（服务端已按 Accept-Language 渲染）。  
- 亦可只返回 `messageKey`+`params`，由前端 `t()` 渲染（二选一，**项目选定后全局统一**；推荐 **服务端渲染 message + 带 messageKey** 便于 MCP/CLI）。

## 8. UI 切换

- **设置 / 偏好对话框** 或顶栏语言菜单：列出 Tier-1。  
- 切换后立即生效（无需重启）；Desktop 托盘下次刷新。  
- 文档截图以 `en` + `zh-Hans` 为主。

## 9. 分期

| 包 | 内容 |
|---|---|
| **I18N-0** | 框架、键规范、`en`+`zh-Hans` 全量迁移现有 UI/错误；Tier-1 其它语言先建文件骨架 + 核心壳文案 |
| **随 M1d** | 连接会话/录制相关键补齐 **全部 Tier-1** |
| **随各 Mx** | 该功能全部新键 × Tier-1 |
| **I18N-QA** | 伪本地化 CI、缺键检测脚本 |

说明：I18N-0 允许「骨架语言」对未用功能暂用 `en` 回退，但 **一旦某功能标记完成，该功能键不得回退缺失**。

## 10. 目录建议

```text
Frontend/Web/src/locales/
  en/app.json
  zh-Hans/app.json
  zh-Hant/app.json
  ja/app.json
  ...
Backend/locales/   # 或 resources
  en/errors.json
  zh-Hans/errors.json
  ...
```

## 11. 验收（系统级）

- [ ] Tier-1 语言包键集合一致  
- [ ] 默认 `auto` 跟随系统  
- [ ] 切换 `ja`/`de` 后主路径（启停、连接会话、设置）无裸键  
- [ ] API 带 `Accept-Language: en` 返回英文错误  
- [ ] MCP 可按 locale 取本地化 message  
- [ ] Skill 中英说明仍有效
