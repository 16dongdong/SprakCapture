# 36 UI 组件规范

本文约定 **可复用界面组件** 的视觉、结构、交互与文案语义，供实现与设计对齐。  
**不包含代码**；层级与路由以 [35](35-uiShellAndNavigation.md) 为准。

配套：

- 层级 / 对话框体系 → [35](35-uiShellAndNavigation.md)
- 图标与字体资源 → [thirdPartyAssets.md](../thirdPartyAssets.md)
- 各功能操作路径 → 对应 `00–33` 的「UI 操作指南」

---

## 1. 设计原则

| 原则 | 要求 |
|---|---|
| Charles 式信息密度 | 工作台紧凑；对话框表单行高适中，避免大卡片堆叠 |
| 层级分明 | L2 工作台视觉最重；L3 浮层居中+遮罩；L4 再其上 |
| 配置与观察分离 | 规则编辑只在对话框组件内；检查器只读分析 |
| **能折则折、忌平铺** | **凡可用收缩/展开呈现的内容，不得整页平铺。** 默认折叠次要块，只展开当前任务相关区；见 §1.1 |
| 文案 i18n | 用户句走语言键（见 [42](42-i18n.md)）；专有工具名可保留英文（Map Local） |
| 可预测 | 同类对话框按钮顺序、Esc/应用语义全局一致 |
| 单一主操作 | 每个表面最多一个主按钮（实心强调色） |

### 1.1 折叠优先（强制）

**判定：能做成收缩展开控件就不要平铺。**

| 应折叠（默认收起或仅展开一项） | 可常显（短、高频） |
|---|---|
| 「说明 / 帮助 / 更多」长文 | 工具总开关、主操作按钮 |
| 高级选项、超时、缓冲、实验项 | 名称、启用、2–4 个主字段 |
| 规则行的扩展详情（多行 JSON、正则标志全集） | 规则表摘要列 |
| 检查器中较少用的子视图细节 | 当前页签主内容 |
| 概览页次要指标组 | 服务状态、录制状态 |
| 多段无关表单 | 当前步骤/当前页签字段 |
| 语言列表很长时的分组 | 当前语言显示 |

**交互约定：**

1. 使用 **Disclosure / Accordion / Tree**（组件 ID：`CollapsibleSection`，见 §7.x），标题行可点，带 ▸/▾ 或等价图标。  
2. **默认状态**：高级/说明类 **默认折叠**；用户展开状态可按对话框 ID 持久化（可选）。  
3. **手风琴**：同一组高级块默认 **同时只展开一个**（可配置允许多开，但不得默认全开）。  
4. **摘要行**：折叠时在标题右侧显示一行 muted 摘要（如「3 条规则 · 已启用」），避免必须展开才能知状态。  
5. **禁止**：一屏平铺 8+ 个等权重输入块；用超长滚动代替信息架构。  
6. **无障碍**：折叠头 `aria-expanded`；键盘 Enter/Space 切换。

```text
┌─ Map Local ─────────────────────────────┐
│ ☑ 启用 Map Local                         │
│ ┌ 规则 ─────────────────────────────┐   │  ← 主区常显
│ │ 表 …                                │   │
│ └────────────────────────────────────┘   │
│ ▸ 说明与示例                    已折叠   │  ← 能折则折
│ ▸ 高级（MIME 覆盖 / 缺文件策略） 已折叠   │
│              [取消] [应用] [确定]         │
└─────────────────────────────────────────┘
```

## 2. 设计令牌（Design Tokens）

实现应映射到 CSS 变量（现有 `app.css` 的 `clamp` 令牌可演进，但 **语义名** 以下表为准）。

### 2.1 间距

| Token | 用途 | 参考值（基准 1040 宽） |
|---|---|---|
| `space.2` | 图标与文字间隙、表内紧贴 | 4px |
| `space.3` | 控件组内、紧凑列表行距 | 6px |
| `space.4` | 表单行间距、工具条按钮间距 | 8px |
| `space.5` | 对话框内容块之间 | 12px |
| `space.6` | 面板内边距（工作台栏） | 10–14px |
| `space.8` | 对话框外边距/大分段 | 16–20px |

**规则：**

- 对话框内容区：外圈 `space.6`–`space.8`，块间距 `space.5`。
- 表单「标签–控件」：同行标签宽固定 96–120px，或上下结构时标签下 `space.2`。
- 禁止在同一对话框混用「超大 32px 空隙」与「4px 挤在一起」两种节奏。

### 2.2 字号与字重

| Token | 用途 | 参考 |
|---|---|---|
| `font.caption` | 底栏、表头次要、时间戳 | 11–12px |
| `font.body` | 默认正文、表单、菜单 | 12–13px |
| `font.label` | 表单标签、页签 | 12–13px，可 medium |
| `font.title.dialog` | 对话框标题 | 14–15px，semibold |
| `font.title.page` | 概览页标题（若有） | 18–20px |
| `font.mono` | URL、Hex、状态码、路径 | 等宽，同 body 尺寸 |

字体栈见 [thirdPartyAssets.md](../thirdPartyAssets.md)：系统 UI 字体，不打包 Webfont。

### 2.3 控件高度

| Token | 用途 | 参考 |
|---|---|---|
| `control.sm` | 表格内嵌勾选、小图标钮 | 22–24px |
| `control.md` | 默认按钮、输入框、下拉 | 28–32px |
| `control.lg` | 顶栏主状态动作 | 32–36px |
| `toolbar.height` | 顶栏总高 | 40–44px |
| `statusbar.height` | 底栏总高 | 20–22px |
| `row.transaction` | 结构报文行高 | 26–30px |
| `row.tree` | 结构树行高 | 24–28px |

### 2.4 圆角与描边

| Token | 值 | 用途 |
|---|---|---|
| `radius.sm` | 4px | 输入框、小按钮、页签 |
| `radius.md` | 6–8px | 对话框、菜单、卡片 |
| `radius.pill` | 999px | 仅角标/开关轨道（可选） |
| `border.default` | 1px 实线，中性色 | 分割、输入 |
| `border.focus` | 2px 强调色或外发光 | 焦点环，不得去掉 |

### 2.5 颜色角色（语义，不锁死色值）

| 角色 | 用途 |
|---|---|
| `bg.app` | 主窗口背景 |
| `bg.panel` | 结构/检查器面板 |
| `bg.elevated` | 对话框、弹出菜单 |
| `bg.overlay` | 遮罩，建议黑 40–50% |
| `bg.selected` | 表/树选中行 |
| `bg.hover` | 悬停 |
| `fg.primary` / `fg.secondary` / `fg.muted` | 文字三级 |
| `fg.danger` | 错误、中止、破坏 |
| `fg.success` | 成功极少使用，优先靠状态文案 |
| `accent` | 主按钮、录制中、链接 |
| `border` | 默认边框 |
| `status.recording` | 录制红点 |
| `status.warning` | 达上限、白名单危险 |

**对比度：** 正文与背景满足可读；禁用态用降透明+禁用指针，不只靠变灰到不可读。

### 2.6 阴影与层级

| 表面 | 阴影 |
|---|---|
| 菜单 / 右键 | 轻阴影 |
| L3 对话框 | 中阴影 + 遮罩 |
| L4 对话框 | 略重于 L3，或同样阴影但 z-index 更高 |
| Toast | 高于 L4 |

## 4. AppShell / 顶栏 / 底栏 / 菜单

### 4.1 AppShell

- 纵向：`MenuBar`（Desktop 可系统菜单；Web 可用仿菜单栏）→ `TopToolbar` → `main` → `StatusBar`。
- `main` 仅渲染 L2（概览或连接会话）；对话框经 `DialogHost` 传送到 `body` 级，不塞进 `main` 滚动容器。

### 4.2 TopToolbar

**分区（左 → 右）：**

1. 品牌标记（非按钮）  
2. 主导航：仅「概览」「连接会话」——`Segmented` 或 `NavLink` 样式，**当前页**有明确选中底/线  
3. 弹性空白  
5. 工具图标组：刷新、清空、导出…、悬浮窗  
6. 主状态动作：启动/停止服务（唯一大强调按钮）

**规范：**

- 开关类：按下/开启有填充或描边高亮；录制开启用 `status.recording` 圆点脉冲（弱动画，可关）。  
- 图标按钮：正方形命中区 ≥ 28px；`title` + `aria-label` 中文。  
- 带 `…` 的导出：表示打开对话框。  
- 开关 **右键** 打开对应设置对话框（与 35 一致）；需在组件文档/帮助中说明。  
- 禁用：控制未连接时清空/启停等按状态禁用，不隐藏。

### 4.3 StatusBar

- 单行、不换行；段之间用浅分隔或 `·`。  
- 可点击段：手型 + hover 底；点击打开对应 L3 或错误详情。  
- 错误段用 `fg.danger`，最多展示约 40 字，完整进详情。

### 4.4 AppMenuBar

- 菜单项文案：动作名词；打开对话框的项后缀 **`…`**。  
- 开关类菜单项：左侧勾选标记与 snapshot 同步。  
- 危险项（清空、再生证书）：可用 `fg.danger` 或分组底部分隔。  
- 快捷键（可选 P1）显示在菜单项右侧，等宽数字。

## 5. 对话框体系（核心）

### 5.1 DialogHost

**职责：**

- 维护对话框栈：`[L3?, L4?]`，断点命中可插到栈顶策略见 35。  
- 打开时：锁住 L2 指针事件；焦点落入对话框。  
- 关闭时：焦点回到打开前的触发控件（菜单/右键目标/顶栏按钮）。

**禁止：**

- 同时打开两个无关 L3（后开替换前开，或入队，产品选 **替换** 并丢弃未应用草稿前确认）。  
- L4 超过一层。

### 5.2 ModalDialog 结构

```text
┌─ [图标?] 标题文字 ──────────────────────────── [帮助?] [×] ─┐
│ 可选：对话框内 Tabs                                           │
│ ┌─ body（可滚动）─────────────────────────────────────────┐ │
│ │                                                         │ │
│ └─────────────────────────────────────────────────────────┘ │
│ 可选：次要说明 / 校验错误条                                    │
│                              [次要…]  [取消] [应用] [确定]    │
└───────────────────────────────────────────────────────────┘
```

| 区域 | 规范 |
|---|---|
| 标题 | 与菜单文案一致，如「Map Local」「SSL 代理设置」；不加「对话框」字样 |
| 关闭 × | 等同取消（有未应用更改则确认） |
| body | 最大高度约 `min(640px, 70vh)`，溢出内部滚动，页脚固定不滚走 |
| 宽度 | 小表单 480–560px；规则表 720–920px；向导 560–640px；总宽 `min(指定, 92vw)` |
| 遮罩 | 点击不关闭（防丢编辑）；仅 × / 取消 / Esc / 确定 关闭 |
| 动画 | 可选 120–180ms 淡入+微位移；尊重「减少动态效果」系统设置 |

### 5.3 DialogFooter 按钮顺序与语义

**方向：从右到左为主操作区（Windows / Charles 常见）：**

```text
[可选左侧：次要链接或「重置」]     ……     [取消]  [应用]  [确定]
```

| 按钮 | 类型 | 语义 | 备注 |
|---|---|---|---|
| **确定** | `primary` | 提交草稿 → 成功则关闭 | 默认焦点可放在「应用」或「确定」：规则表推荐默认「确定」 |
| **应用** | `secondary` | 提交草稿 → **不关** | 无脏数据时可禁用 |
| **取消** | `ghost/secondary` | 丢弃未应用草稿并关闭 | |
| **关闭** | 只读对话框 | 无草稿时仅关闭 | 关于/说明类 |

**断点命中例外（右对齐）：**

```text
[全部继续]     [中止]  [继续]
```

- **继续** = primary  
- **中止** = danger  
- **全部继续** = secondary  

**向导例外：**

```text
[取消]     [上一步]  [下一步] / [完成]
```

### 5.4 键盘

| 键 | 行为 |
|---|---|
| `Esc` | 先关 L4；再 Esc 关 L3；有未应用更改 → ConfirmDialog |
| `Enter` | 在 `ConfirmDialog` / 单行输入确认框 = 确定；在规则表 L3 **不**全局绑定 Enter 提交 |
| `Tab` | 循环陷阱在当前顶层对话框内 |
| `Ctrl+Enter`（可选） | 等同确定 |

### 5.5 草稿与脏状态

- 打开对话框时拷贝服务端快照为 **草稿**。  
- 控件修改 → `dirty=true`；标题侧可显示未保存点（可选）。  
- **应用** 成功 → `dirty=false`，草稿与权威对齐。  
- 外部 snapshot 在打开期间变更：不静默覆盖草稿；关闭后再打开取新值。冲突时 Toast「配置已在其他处更改」。

### 5.6 校验展示

- 字段下 `caption` 错误文案，`fg.danger`。  
- 页脚上方可汇总一条：「请修正 n 处错误」。  
- **确定/应用** 在存在错误时：不提交，焦点移到首个错误字段。

## 6. 对话框变体规格

### 6.1 ToolRulesDialog（工具规则表）

**组成自上而下：**

1. `Checkbox`「启用 {工具名}」——工具总开关  
2. `RulesTable`（可滚动）——主区常显  
3. 表操作条：`添加…` `编辑…` `删除` `上移` `下移`  
4. `CollapsibleSection`「说明」——**默认折叠**，勿在开关下平铺长说明  
5. `CollapsibleSection`「高级」——**默认折叠**（若有）  
6. `DialogFooter`

禁止：在规则表上方平铺大段帮助段落或把所有高级字段与主表混排。

**RulesTable 列（通用）：**

| 列 | 宽 | 内容 |
|---|---|---|
| 启用 | 36px | 行级 Checkbox |
| 位置 | flex | Location 摘要文本 |
| 动作/目标 | flex | 工具相关摘要 |
| 菜单 | 36px | 行 ⋮ 可选 |

**交互：**

- 双击行 = 编辑…  
- Delete 键 = 删除（需确认若多选）  
- 无数据：表内 `EmptyState`「暂无规则，点击添加」  

### 6.2 RuleEditorDialog（L4）

- 标题：「添加规则」/「编辑规则」。  
- 主体：`LocationFields` + 工具专用字段（路径浏览、替换串等）。  
- 页脚：仅 `[取消] [确定]`（无应用，因父级 L3 统一应用）。  
- **确定** 只写回 L3 草稿行，不直接打 API（除非产品规定右键快速添加且 L3 不存在——默认仍进 L3）。

### 6.3 FormSettingsDialog

- 顶部 `Tabs`（对话框内）：如 HTTP | SOCKS5 | 高级——**分页优先于单页平铺全部监听器字段**。  
- 页签内：主字段常显；超时/缓冲/实验项放入 `CollapsibleSection`「高级」，**默认折叠**。  
- 运行中锁定字段：`disabled` + 旁注 `caption`（i18n 键）。  
- 页脚标准 取消/应用/确定。  
- 禁止：一个页签内无分组地平铺 15+ 表单项。

### 6.4 WizardDialog

- 顶部步骤指示：`1 连接 → 2 证书 → 3 完成`（当前步强调）。  
- 内容区固定最小高度，避免步进时对话框狂跳。  
- 最后一步主按钮文案为 **完成**。

### 6.5 ConfirmDialog

- 宽度 400–440px。  
- 文案：标题短 + 正文说明后果。  
- 破坏性：主按钮用 danger「删除」/「清空」；默认焦点在 **取消**。  
- 非破坏：主按钮 primary，默认焦点在确定。

### 6.6 BreakpointHitDialog

- 左：挂起列表（transaction 摘要）。  
- 右：可编辑头表 + 正文编辑器（复用 BodyViewer 编辑模式）。  
- 无「应用」；**继续** 即提交该条。  
- 超时：列表项显示剩余时间；到期按策略移除并 Toast。

## 7. 表单控件

### 7.0 CollapsibleSection（折叠区块）

| 属性 | 说明 |
|---|---|
| `title` | 标题（i18n） |
| `summary` | 折叠时右侧一行摘要（可选） |
| `defaultOpen` | 默认 `false`（高级/说明必须 false） |
| `children` | 展开后内容 |

- 标题行整行可点；左侧 ▸/▾；高度 `control.md` 量级。  
- 展开动画可选、短；尊重减少动态效果。  
- 嵌套折叠最多 **两层**；更深用 L4 对话框。  
- **验收：** 同类信息若存在折叠实现，PR 不得改为整段平铺。

### 7.1 通用

| 状态 | 表现 |
|---|---|
| default | 边框 `border`，bg elevated/input |
| hover | 边框略深 |
| focus | `border.focus`，不靠 outline:none 裸奔 |
| error | 边框 danger + 下方错误文案 |
| disabled | 50% 透明或 muted bg，禁止点击 |

- 占位符用 `fg.muted`，不替代标签。  
- 必填：标签后 `*` 或「（必填）」，勿只靠颜色。

### 7.2 TextField / NumberField

- 高度 `control.md`。  
- Number：禁止滚轮在未聚焦时改值；非法输入不写入 NaN（保持上次有效或空+错误）。  
- 密码：永不自动填充来自 snapshot 的口令；切换显示用 `IconButton` 眼睛。

### 7.3 Checkbox / 开关

- 工具总启用：优先 **Checkbox + 文案**（Charles 风格清晰）。  
- 顶栏瞬时开：可用按钮式 toggle 或图标按下态。  
- 三态不用于规则启用。

### 7.4 Select / Combo

- 长列表可搜索（主机类 P2）。  
- 菜单层级用系统/组件弹出，z-index 高于 L3 body。

### 7.5 LocationFields

**字段顺序固定：**

1. 协议（Select：\* / http / https / …）  
2. 主机（Text）  
3. 端口（Text，可范围）  
4. 路径（Text）  
5. 查询（可选，默认折叠）  

- 提供 **试匹配** 次要按钮：展开结果区绿/红文案。  
- 摘要一行算法：`https://host:port/path` 空段省略。

### 7.6 文件/目录选择

- 控件 = 只读路径框 + **浏览…** 按钮。  
- Desktop：系统选文件/夹；Web：输入路径或 file input（能力不足时说明「请使用桌面版浏览」）。  
- 路径过长中间省略，tooltip 全文。

## 8. 工作台组件（L2）

### 8.1 WorkspaceConnections

- 双栏：`TransactionTree | TransactionInspector`。
- `Splitter`：拖拽柄 4–6px 命中；双击还原默认比例；比例持久化。  
- 窄屏：改为上下堆叠，结构报文 → 检查器，规范见 frontendArchitecture。

### 8.2 TransactionTree

- 缩进每级 12–16px；展开三角命中区充足。  
- 只按 `host:port` 建立端点分组；组内直接展示真实事务报文，不生成路径目录。
- 选中/悬停背景分明；主机、资源类型与状态图标可区分。
- 聚合徽章（条数/错误）用 `caption`，不抢主机名。  
- 结构区使用虚拟滚动；宽度不足时水平滚动，位置和类型不得省略。
- 报文选中单选为主；多选 Shift/Ctrl 用于导出/批量保存。
- 进行中可用弱脉冲或「…」；减少动态效果模式下保持静态。
- 右键：`ContextMenu`。

### 8.3 FilterBar

- 高度紧凑；搜索框占弹性宽。  
- 过滤即时（防抖 150–200ms）；清除一键。  
- 「仅聚焦」「仅错误」用 Checkbox，不要做二级页面。

### 8.4 TransactionInspector

- 顶：`Tabs`（概览/请求/响应/汇总/图表/备注/工具…）——**用页签切换，不把所有子视图纵向平铺**。  
- 请求/响应内再 `SegmentedControl` 或二级 Tabs：Headers / JSON / Hex…  
- 概览内次要诊断块用 `CollapsibleSection`（如 TLS 细节、完整计时拆解），**默认折叠**。  
- 无选中：`EmptyState`，文案 i18n。  
- 工具页签只读；工具名可链式打开对应 ToolRulesDialog。

### 8.5 BodyViewer

| 子视图 | 要求 |
|---|---|
| Text | 可软换行开关；等宽可选 |
| JSON/XML | 树 + 格式化；错误标行 |
| Hex | 固定列宽；偏移列 muted |
| Image | 居中预览；失败回 Text |
| Raw | 标注是否已解压 |

超大：首屏预览 + 「加载更多/导出完整」。

### 8.6 OverviewPage

- 卡片网格，只读；不嵌完整表单。  
- 次要指标组、历史说明放入折叠卡或「更多指标」Disclosure，**不要一屏铺满所有图表**。  
- 卡片可点「配置」链到 FormSettingsDialog。

### 8.7 FloatingPanel

- 只放：服务状态、录制/节流/断点/启停、一键回主窗。  
- 不放规则表。

## 9. 反馈组件

### 9.1 Toast

- 位置：主窗口右上或底栏上方，不挡对话框主按钮。  
- 时长：成功 3s；错误 5s 或手动关；同内容合并。  
- 种类：info / success / warning / error（图标+文案）。

### 9.2 EmptyState

- 图标 + 主文案 + 可选次要说明 + 可选行动按钮（「添加规则」打开 L4）。  
- 用于：空结构、空规则表、未连接控制面。

### 9.3 Badge

- 顶栏断点角标：数字，最大 `99+`。  
- 菜单工具启用：用勾选而非数字角标。

### 9.4 InlineBanner

- 对话框或工作台顶部警告条（如绑定 0.0.0.0）；可关闭的写入 sessionStorage。

---

## 10. 右键菜单 ContextMenu

- 最小宽 180px；项高 28–30px；分隔线 1px。  
- 危险项单独分组。  
- 带 `…` 打开对话框；即时动作无 `…`。  
- 快捷键提示右对齐 muted。  
- 打开时：菜单在指针旁，避让视口边缘。  
- 与对话框同时：右键优先于 L2；L3 打开后 L2 右键禁用。

---

## 11. 按钮 Button 规格

| 变体 | 用途 |
|---|---|
| `primary` | 确定、继续、启动（进行中可变为停止样式） |
| `secondary` | 应用、全部继续、次要行动 |
| `ghost` | 取消、工具条弱操作 |
| `danger` | 中止、删除、清空确认主按钮 |
| `icon` | 顶栏图标，方形 |

- 文案：2–4 字优先（确定、应用、取消、添加…）。  
- 加载中：按钮内 spinner，禁用重复点；保留原宽度防抖。  
- 图标+文字：图标在左，间距 `space.2`。

---

## 12. 无障碍与可用性

- 所有图标按钮有中文 `aria-label`。  
- 对话框 `role="dialog"` + `aria-modal="true"` + `aria-labelledby` 指向标题。  
- 焦点可见，永不 `outline: none` 而无替代。  
- 颜色不作为唯一状态信息（录制红点同时有底栏文字）。  
- 目标尺寸：可点控件短边 ≥ 24px，推荐 28px+。

---

## 13. 动效与性能

- 非必要不循环动画；脉冲仅录制点、进行中行可选。  
- 结构虚拟列表：窗口外不挂载正文查看器。
- 对话框打开不重挂载整个连接会话树（保持 L2 实例，仅 pointer-events: none）。

## 14. 文案约定

| 场景 | 文案 |
|---|---|
| 打开配置 | 菜单/按钮带 `…` |
| 成功写入 | Toast「已应用」/「已保存」 |
| 失败 | 中文原因，不露出 stack |
| 空规则表 | 「暂无规则」 |
| 未连接 | 「未连接本地控制服务」 |
| 需停服务 | 「请先停止服务再修改」 |
| 确认清空 | 「将删除当前全部事务，此操作不可撤销」 |

工具专有名：可中英并存，如「Map Local（本地映射）」标题用短名「Map Local」，说明里用中文。
